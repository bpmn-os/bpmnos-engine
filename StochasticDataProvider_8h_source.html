16/**
17 * @brief Data provider supporting stochastic behavior.
18 *
19 * StochasticDataProvider supports:
20 * - 3-column format (INSTANCE_ID, NODE_ID, INITIALIZATION) - static behavior
21 * - 4-column format (+ DISCLOSURE) - dynamic behavior
22 * - 6-column format (+ READY, COMPLETION) - stochastic behavior
23 *
24 * Has its own LIMEX handle with lookup tables from Model plus random functions.
25 *
26 * @note CSV ordering: For dependent expressions, parent node rows must be listed
27 * before child node rows in the CSV file. If a child expression depends on
28 * a parent's deferred attribute, the parent must be evaluated first.
29 *
30 * @note Guidance constraint: Guidance expressions must only reference attributes
31 * that are disclosed at the time of access. This is not enforced; it is
32 * the user's responsibility to ensure correct usage.
33 */
