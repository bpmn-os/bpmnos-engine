16/**
17 * @brief Class reading the instance data of a data provider from a CSV table.
18 *
19 * The data provider gives the names of the columns it reads in their order. The first three columns hold the
20 * instance, the node, and the initialization, which has the form `attribute := expression`, and the further
21 * columns are interpreted by the data provider alone. The first line of the table names its columns, which
22 * must be the first three or more of the columns given by the data provider; a column the table lacks gives
23 * no input. A row without instance and node gives the value of a global attribute and has no further cells,
24 * and every other row belongs to an instance, the first row of which must name the process of the instance.
25 *
26 * The reader resolves the rows and offers what every data provider needs to interpret them: the lookup of
27 * the attribute an initialization gives a value to, the evaluation of global values and of expressions of
28 * an instance with a LIMEX handle chosen by the data provider, and the default values of the instance and
29 * the timestamp. How the values of an instance are used is left to the data provider.
30 */
31class InstanceDataReader {
32public:
33 /**
34 * @brief Row of the table, giving the value of a global attribute if it names no node.
35 */
36 struct Row {
37 size_t instanceId; ///< The identifier of the instance, zero for a global value
38 const BPMN::Node* node; ///< The node the row refers to, nullptr for a global value
39 std::string initialization; ///< The initialization, possibly empty
40 std::vector<std::string> cells; ///< The cells of the further columns in the order given by the data provider, empty for a column the table lacks
41 };
42
