BPMNOS::Execution::MessageDeliveries Class Reference

Message delivery decision candidates, ranked by reward. More...

Detailed Description

A message delivery request can be fulfilled by a created Message whose origin is an admissible sender and whose header matches the recipient header. notice collects the matching request/message pairs; evaluateCandidates evaluates each (after updating the recipient's status with the message), so the front of the reward-ordered set is the best feasible delivery (best-of-all, for the competing layer).
