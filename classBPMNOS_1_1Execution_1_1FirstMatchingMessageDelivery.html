BPMNOS::Execution::FirstMatchingMessageDelivery Class Reference

Dispatches the first matching message delivery decision, without evaluation. More...

Detailed Description

A message delivery request can be fulfilled by a created Message when its origin is an admissible sender and its header matches the recipient header. The first matching message delivery decision is dispatched.
