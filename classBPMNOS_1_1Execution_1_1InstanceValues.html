BPMNOS::Execution::InstanceValues Class Reference

The status and the owned data of a scope instance, built when the instance comes into being. More...

Detailed Description

The constructor lays out a slot for every own attribute of the scope, sets the timestamp to the time at which the instance comes into being and gives the instance its identity, if it has one of its own. It then walks over the own attributes of the scope in declaration order, the scalar status attributes, the scalar data attributes and the objects, and gives each its initial value: the value of its initial expression if the model initialises it, otherwise the value given, if any. An expression is evaluated over the status and the data built so far, so that it reads everything inherited, the timestamp, the instance and everything declared before it, and nothing declared after it.

A data provider builds the values of a scope with a ready event when the event becomes due and applies its ready values through assign; the engine builds the values of the scopes it creates itself. The status and the owned data are then moved into the ready event or into the scope created.
