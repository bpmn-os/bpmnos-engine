BPMNOS::Object::Layout Struct Reference

The geometry of an object: a single value, an array or a struct, the schema it lays out, and the number of positions it occupies in the values of the object. More...

Detailed Description

A layout and its schema agree: the layout has the structure of the schema, the schema states the value type of every single value and the name of every field, and every array the schema fixes has the size the schema states. The layout of an element or field refers to the corresponding part of the schema. A layout never changes once built, and refers to the layouts it contains through std::shared_ptr<const Layout>, so that a layout derived from another shares every part it does not change.
