Controller

A controller is responsible for making decisions, i.e.,

  • entry decisions,
  • exit decisions,
  • choice decisions, and
  • message delivery decisions

during process execution.

A controller has to connect to an execution engine to be informed about relevant changes in the system state, i.e., about

  • requests for a decision to
    • enter a node,
    • exit a node,
    • make a choice, or to
    • deliver a message,
  • updates of data attribute values or global attribute values,
  • sequential performers becoming busy or idle, and
  • messages sent.

Moreover, by connecting to the execution engine, the engine is enabled to fetch events which are dispatched by the controller.

Greedy controller

The greedy controller is a controller that holds a list of dispatchers that are consulted in the given order:

  • the exit dispatcher evaluates the pending exit decisions and dispatches the first feasible exit,
  • the entry dispatcher evaluates the pending entry decisions (excluding those in a sequential ad-hoc subprocess) and dispatches the first feasible entry,
  • the direct message dispatcher dispatches a message delivery without evaluation whenever the sender explicitly addresses its recipient or the recipient explicitly refers to the sender,
  • the enumerated choice dispatcher (, )or the bisectional choice dispatcher when config.bisection is set) evaluates choices for decision tasks and as soon as feasible choices are found for a decision task, it dispatches the best evaluated choices for that task,
  • the competing candidates dispatcher evaluates message delivery decisions and entry decisions for activities within sequential ad-hoc subprocesses. It dispatches the best evaluated decision among all.

All evaluations are conducted by an evaluator.

Evaluator

The evaluator is responsible for determining whether a decision can be taken without violating any restrictions and to quantify the value of taking the decision.

Local evaluator

The Local evaluator makes local observations to evaluate a decision.

Guided evaluator

The Guided evaluator makes local observations and includes guidance provided with the model to evaluate a decision.
