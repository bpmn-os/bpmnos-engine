9/**
10 * @brief Represents a pending message delivery, together with the header the awaiting token is matched by.
11 *
12 * The header is built once, from what the token holds when it comes to await a delivery, and is kept for as
13 * long as the request is pending. That is the semantics of a delivery: a message is matched against what
14 * the recipient presented when it began waiting, not against what it holds when a message happens to
15 * arrive, so a data or global attribute written meanwhile does not change what this token accepts.
16 *
17 * Holding it here rather than rebuilding it means every candidate collector, every dispatcher and every
18 * caller matches against the same header, and `MessageDefinition::getRecipientHeader` has one caller.
19 */
20struct MessageDeliveryRequest : DecisionRequest {
21 MessageDeliveryRequest(const Token* token, BPMNOS::Values recipientHeader)

23 , recipientHeader(std::move(recipientHeader))
