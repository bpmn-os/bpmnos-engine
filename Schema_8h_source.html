39/**
40 * @brief A type: a value type, an array type or a struct type.
41 *
42 * A schema is written in the notation `schema := ( valuetype | "{" field ( "," field )* "}" ) dimension*`, with
43 * `field := name ":" schema` and `dimension := "[" n "]" | "[]"`, a dimension `[n]` denoting a fixed array of size
44 * `n` and `[]` an open array. The dimensions are written outermost first: `boolean[3][4]` is the array type of size
45 * 3 whose element type is the array type of size 4 whose element type is `boolean`.
46 *
47 * A schema never changes once built, and refers to the schemas it contains through `std::shared_ptr<const Schema>`,
48 * so that a schema derived from another shares every part it does not change.
49 */
50struct Schema : std::variant<ValueType, ArrayType, StructType> {
51 using variant::variant;
52 Schema() = default;
53
54 /**
55 * @brief Constructs the target schema of an assignment to an object of the given current layout, whose effective
56 * schema is given.
57 *
58 * The schema has the structure of the effective schema. Every array that is fixed in the effective schema is fixed
59 * at the size it has in the current layout, and every open array stays open, so that an assignment keeps the size
60 * of a fixed array, which may have been resized during the run, and gives an open array the size of the source.
61 */
62 Schema(const Schema& effectiveSchema, const BPMNOS::Object::Layout& currentLayout);
63
64 /// @brief Parses the notation of a type, throwing an error describing the first violation of the grammar.
65 static Schema parse(const std::string& text);
66 /// @brief Returns the notation of the type in its canonical form.
67 std::string stringify() const;
68 /// @brief Returns true if the schemas describe the same type: the same value types, the same arrays with the same
69 /// sizes, and the same fields, in the same order and with equal types.
70 bool operator==(const Schema& other) const;
71 /**
72 * @brief Returns true if every object of the given source schema is, unchanged, an object of this schema.
73 *
74 * The two schemas must have the same structure, the same value types and the same fields in the same order, and at
75 * every array type this array must be open or both arrays must be fixed at the same size.
76 */
77 bool supports(const Schema& source) const;
78
79 /**
80 * @brief Returns the schema with the sizes a size declaration states, given as the text following the name of the
81 * attribute.
82 *
83 * The text is a path of steps, e.g. `[6].flags[3]`. A step `[n]` states the size `n` for the next array, a step
84 * `[]` states no size for it, and a step `.name` descends into the field `name`. The returned schema has new parts
85 * along the path and shares every other part with this schema. A size of 0, a size contradicting one fixed before,
86 * an index step where the schema has no array, and an unknown field are errors.
87 */
88 Schema declareSizes(const std::string& declaration) const;
89};
