12/**
13 * @brief Utility class replacing every literal in a text by the number encoding it.
14 *
15 * The engine represents a string by its index in the string registry and a collection by its index in
16 * the collection registry, so that every value is a number. Text stating such a value must therefore be
17 * scanned before it is read as a value or parsed as an expression, and this class is the one place in
18 * which that is done, so that what a lexeme is is decided once.
19 *
20 * The text is read once, from left to right, and each thing met is dealt with where it is met.
21 *
22 * A quoted span is read to its closing quote and emitted as its index in the string registry. A quote
23 * within it does not occur, quotes not being escaped, and a comma or a bracket within it is text rather
24 * than structure.
25 *
26 * A bracket either opens a collection literal or belongs to the expression it stands in, and which of
27 * the two is decided by what has been emitted last. After a name, a closing bracket or a closing
28 * parenthesis it indexes a collection, and after a membership operator it states a collection the
29 * expression parser reads itself, so in both cases the bracketed text is copied and its contents are
30 * scanned where they stand. Everywhere else the bracket opens a literal. The members of a literal are read one by one, each by the same rules, so that
31 * a member is a quoted string, a truth value, a number, or a literal of its own, to any depth. The
32 * members must agree in the type they are recorded as, a member that is a literal being recorded as a
33 * collection whatever it holds, and the literal is registered with the type they agree on and emitted as
34 * its index in the collection registry. A numeric member is recorded as a decimal, so that a literal may
35 * hold whole and fractional numbers alike and both are written out as they were read.
36 *
37 * Everything else, which is to say names, numbers, operators, whitespace, and the delimiters of a line,
38 * is copied unchanged, a membership operator included. Of the grammar the expression parser applies, the
39 * scan knows what decides a bracket and nothing besides, so that the text it emits is read as the text
40 * it was given.
41 *
42 * A text that cannot be read is refused, naming it: a quote that is not closed, a literal that is not
43 * closed, a literal without members, a member without a value, a member that is neither a truth value
44 * nor a number nor a literal, and members that do not agree in type.
45 */
46class InputEncoder {
47public:
48 /// Constructor scanning the given text.
49 InputEncoder(const std::string& input);
50
51 /// Returns the text with every literal replaced by the number encoding it.
52 const std::string& text() const { return encoded; }
53
54 /// Returns the type of the literal if the text states one literal and nothing besides whitespace, and
55 /// no value otherwise. This is what a caller needs where the text states a value rather than an
56 /// expression, the type of an expression following from its shape rather than from its text.
57 const std::optional<ValueType>& type() const { return literalType; }
58
59 /// Returns a part of a text that has been scanned already, such as one alternative of an enumeration.
60 /// No type is stated, a part of a text being no literal of its own.
61 static InputEncoder fragment(std::string text);
62
63private:
64 /// Constructor adopting text that has been scanned already.
65 InputEncoder(std::string text, std::nullopt_t);
66
67 std::string encoded;
68 std::optional<ValueType> literalType;
69};
