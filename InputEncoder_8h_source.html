15/**
16 * @brief Utility class replacing every literal in a text by the number encoding it.
17 *
18 * The engine represents a string by its index in the string registry and a literal array or value with
19 * fields by the index of the constant object it states in the object registry, so that every value is a
20 * number. Text stating such a value must therefore be
21 * scanned before it is read as a value or parsed as an expression, and this class is the one place in
22 * which that is done, so that what a lexeme is is decided once.
23 *
24 * The text is read once, from left to right, and each thing met is dealt with where it is met.
25 *
26 * A quoted span is read to its closing quote and emitted as its index in the string registry. A quote
27 * within it does not occur, quotes not being escaped, and a comma or a bracket within it is text rather
28 * than structure.
29 *
30 * A bracket either opens an array literal or belongs to the expression it stands in, and which of the two
31 * is decided by what has been emitted last. After a name, a closing bracket or a closing parenthesis it
32 * indexes, and after a membership operator it states a set the expression parser reads itself, so in both
33 * cases the bracketed text is copied and its contents are scanned where they stand. Everywhere else the
34 * bracket opens a literal. A brace opens a literal with fields, `{ name := value, ... }`, where a literal may
35 * stand and a name followed by `:=` follows it; any other brace is a set or the body of an aggregation and is
36 * copied. The members of an array and the values of the fields are read one by one, each by the same rules,
37 * so that each is a quoted string, a truth value, a number, or a literal of its own, to any depth. A numeric
38 * value is recorded as a decimal, so that a literal may hold whole and fractional numbers alike and both are
39 * written out as they were read. The members of an array are uniform: they agree in type and, being arrays
40 * or values with fields themselves, in the sizes of their arrays and in their fields. The literal is
41 * registered in the object registry as a constant object, stored flat, and emitted as its index there.
42 *
43 * Everything else, which is to say names, numbers, operators, whitespace, and the delimiters of a line,
44 * is copied unchanged, a membership operator included. Of the grammar the expression parser applies, the
45 * scan knows what decides a bracket and nothing besides, so that the text it emits is read as the text
46 * it was given.
47 *
48 * A text that cannot be read is refused, naming it: a quote that is not closed, a literal that is not
49 * closed, an array without members, a member without a value, a member that is neither a truth value nor a
50 * number nor a literal, members that are not uniform, and a field without a name, without `:=` or stated
51 * twice.
52 *
53 * A text may be scanned admitting object initializers, as the instance data are, where an object is given a
54 * literal whose members may be expressions. A literal with an expression member is then neither registered nor
55 * refused but copied unchanged, so that it is read by @ref ObjectInitializer where it initialises an object,
56 * and its span tells a reader splitting the text that no delimiter within it separates anything.
57 */
58class InputEncoder {
59public:
60 /// Constructor scanning the given text, admitting object initializers if requested.
61 InputEncoder(const std::string& input, bool initializers = false);
62
63 /// Returns the text with every literal replaced by the number encoding it.
64 const std::string& text() const { return encoded; }
65
66 /// Returns the index in the object registry of the constant object if the text states one literal array or
67 /// value with fields and nothing besides whitespace, and no value otherwise. This is what a caller needs where
68 /// the text states an object rather than an expression.
69 const std::optional<size_t>& object() const { return literalObject; }
70
71 /// Where a literal stands in the text with every literal replaced: the positions of the first character of
72 /// the number encoding it, or of an object initializer copied unchanged, and of the character following it, and
73 /// what it is.
74 struct Span {
75 enum class Type { STRING, OBJECT, INITIALIZER };
76 size_t begin;
77 size_t end;
78 Type type;
79 };
80
81 /// Returns where each literal stands in the text with every literal replaced, in their order, so that a
82 /// reader splitting that text can tell a cell stating a literal from a cell stating a number.
83 const std::vector<Span>& spans() const { return literalSpans; }
84
85 /// Returns the indices in the object registry of the constant objects the literals of the text state, in
86 /// their order, so that a caller can tell a number standing for a constant object from a number. A part of
87 /// a text scanned already states none.
88 const std::vector<size_t>& objects() const { return literalObjects; }
89
90 /// Returns a part of a text that has been scanned already, such as one alternative of an enumeration.
91 /// No type is stated, a part of a text being no literal of its own.
92 static InputEncoder fragment(std::string text);
93
94 /// The syntax tree of a literal as it is read, before it is registered as a constant object or instantiated: a
95 /// scalar, an expression member of an object initializer, an array, or a value with fields. The types are
96 /// defined where literals are read, so that no other code builds or inspects a tree.
97 struct Literal;
98 struct Scalar;
99 struct Expression;
100 struct Array;
101 struct Fields;
102
103private:
104 /// Constructor adopting text that has been scanned already.
105 InputEncoder(std::string text, std::nullopt_t);
106
107 std::string encoded;
108 std::optional<size_t> literalObject;
109 std::vector<size_t> literalObjects;
110 std::vector<Span> literalSpans;
111};

113/**

115 *
116 * The literal is read by the rules of the literals of @ref InputEncoder, except that a member that is neither a

118 * bracket or closing brace standing outside every parenthesis, bracket, brace and quote, and its text is scanned

122 */
