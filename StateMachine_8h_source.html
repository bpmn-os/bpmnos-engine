17/**
18 * @brief Represents a state machine for BPMN execution of a scope in the model.
19 *
20 * This class manages all tokens for BPMN execution of a given scope.
21 *
22 * @par Ownership Hierarchy
23 * All (sub)processes containing flow tokens are owned by a token via Token::owned.
24 * Root state machines (in SystemState::instances) only hold a single process-level
25 * token (node=nullptr). That token owns the child state machine containing the actual
26 * flow tokens. Subprocesses follow the same pattern: a token at the subprocess node
27 * owns a child state machine with the subprocess's flow tokens.
28 *
29 * @note A state machine without @ref parentToken represents a @ref BPMN::Process.
30 * @note Inclusive gateways are not yet supported.
31 *
32 * @attention Event subprocesses within event subprocesses are not yet tested (and may not be supported).
33 */
