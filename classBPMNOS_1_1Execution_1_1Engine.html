Does not process any further event; call run, resume, or step afterwards. The opening clock tick is announced like any other, so the record stream states the time the run begins at and deferred data is disclosed for that instant.

◆ run()

void Engine::run ( const BPMNOS::Model::Scenario *  scenario,
BPMNOS::number  startTime = 0,
BPMNOS::number  endTime = std::numeric_limits<BPMNOS::number>::max() 
)

Creates a fresh system state at the given start time and executes until no tokens remain, no new instantiations are pending, or the end time is exceeded. The start time must not be later than the scenario's earliest instantiation time, since an instance is instantiated at the instant its instantiation time is reached and a later start would leave every earlier instance uncreated.

Parameters
scenarioThe scenario to execute
startTimeTime the run begins at
endTimeLast time to process (engine stops when time >= endTime)
