◆ advance()

bool Engine::advance ( )

Performs one round, asking the environment for an event, then the dispatchers of the controller, and notifying the environment if neither supplied one, and advances the system state by the event obtained as far as possible without fetching the next event. If the round yields no event, it pauses for a moment and returns without processing one.

Returns
False once a termination event has been processed, and true otherwise.

◆ broadcastSignal()

void Engine::broadcastSignal ( Signal signal)
protected

The signal is announced before it is delivered anywhere, so that what is observed is the signal rather than what it causes. It is taken by value because it is broadcast from a command and the content it carries is fixed where the signal arises.

Called for a signal thrown at a signal throw event and for one the environment raises through a SignalBroadcastEvent, so that a signal from outside reaches recipients exactly as one from inside.

◆ run()

void Engine::run ( std::unique_ptr< Scenario > scenario,
BPMNOS::number startTime = 0 )

Creates a fresh system state at the given start time and executes until a termination event is processed. The start time must not be later than the earliest instantiation time, since an instance is instantiated at the instant its instantiation time is reached and a later start would leave every earlier instance uncreated.

Parameters
scenarioThe scenario to execute, created by a data provider built on the model of the engine
startTimeTime the run begins at
Exceptions
std::invalid_argumentif the scenario is not one of the model of the engine

◆ triggerInstanceByMessage()

void Engine::triggerInstanceByMessage ( const BPMN::Process * process,
std::weak_ptr< Message > message_ptr )
protected

No token awaits a message at the message start event of a process, the instance not existing before the message arrives, so no MessageDeliveryRequest is created for it and no MessageDeliveryEvent is ever dispatched. What such an event would do for the message and for the sender is therefore done here: the message is marked as delivered and withdrawn from the message pool, and a token at a send task awaiting its delivery is completed.

◆ wait

std::function<void()> BPMNOS::Execution::Engine::wait = [] { std::this_thread::sleep_for(SLEEP); }

By default it sleeps for SLEEP. A caller driving the run on the same thread sets a function giving it its turn before the run, in which it may read the system state and enqueue events, which the next round processes, but neither advances nor resumes the run. Each engine holds its own function.
