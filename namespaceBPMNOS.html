◆ to_value()

Value BPMNOS::to_value ( std::optional< double > result)

An expression is evaluated at the precision of a double, whereas a value is a number, so a result that becomes a value is converted here. The conversion loses precision and is therefore asked for rather than done on the way out of the evaluation, so that a caller deriving further values from a result — the discretizer of a choice being the one that does — keeps the precision it was evaluated at.
