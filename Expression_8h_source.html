16/**
17 * @brief Class representing a mathematical expression.
18 *
19 * The expression is compiled by LIMEX. Its variables are scalar attributes, passed to LIMEX by value. An access
20 * path such as `facilities[i].cost`, `grid[i][j]` or `x[i]` addresses a part of the array or object an object
21 * attribute holds, and a name used as an array, on the right of `in`, as the argument of an aggregator or in a
22 * binding of an aggregation, is a path without steps, addressing the whole array; LIMEX evaluates its
23 * indices, counting from one, and the expression resolves the path against the layout of the object it
24 * addresses, without copying any value.
25 *
26 * Every name and path is bound to its attribute when the expression is compiled and checked against the
27 * attribute's schema: every index takes the next dimension, a field may only follow once every dimension is
28 * indexed, a path used as a value must address a scalar value, and an array used as such must be an array of
29 * scalar values with a single dimension. The argument of `size` may be any array, its length being all that is
30 * read. An undefined element read as a value makes the expression undefined, except within an aggregation,
31 * whose aggregator skips it.
32 **/
