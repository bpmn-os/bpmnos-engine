BPMNOS::Execution::GreedyController Class Reference

A controller dispatching the first feasible decision in priority order. More...

Detailed Description

Holds a priority-ordered list of dispatchers and dispatches the first feasible decision they yield. Contested entries and message deliveries (which have no precedence over each other) are merged into a single reward-ordered dispatcher, so their best feasible decision competes within the same list rather than in a separate best-of-best stage.
