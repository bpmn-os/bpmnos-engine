19/**
20 * @brief Base class of the data providers feeding the environment of a run with events.
21 *
22 * A data provider holds no state of a run: everything it records about a run is held by the scenario of
23 * the run, which it is given with every call, so that one data provider serves every scenario it creates.
24 * Through the environment it is notified of everything the engine announces, asked for the events due at
25 * the current time, and asked to advance, and it enqueues the events the environment then dispatches in
26 * the order in which they are enqueued.
27 *
28 * A data provider decides whether time advances. When it is asked to advance, neither it nor the
29 * controller having supplied an event at the current time, the base enqueues the next clock tick. A data
30 * provider that has to keep time regardless of the controller, such as one observing the real world,
31 * enqueues its clock ticks when asked for the events due at the current time instead. With a clock
32 * tick duration of zero it does so at once; otherwise it does so once the wall clock has reached the given
33 * number of milliseconds after the previous clock tick, and supplies nothing before. A data provider never
34 * blocks, since the controller may decide while time does not advance.
35 */
36class DataProvider : public std::enable_shared_from_this<DataProvider> {
37public:
38 /**
39 * @param model The model the data provider is built on, whose ownership it shares.
40 * @param clockTickDuration Wall-clock time between two clock ticks, zero advancing time at once and
41 * std::chrono::milliseconds::max() never.
42 */
43 DataProvider(std::shared_ptr<const BPMNOS::Model::Model> model, std::chrono::milliseconds clockTickDuration = std::chrono::milliseconds::zero());
44 virtual ~DataProvider() = default;
