◆ StochasticScenario() [2/2]

StochasticScenario::StochasticScenario ( StochasticScenario *  original,
BPMNOS::number  spawnTime,
unsigned int  seed 
)

Creates a forked scenario to continue a run from a given SystemState. Values with disclosure time >= spawnTime are re-evaluated using the new seed, enabling independent sampling of future stochastic values.

Note
spawnTime must be the next point in time after the given SystemState's current time (i.e., systemState->getTime() + 1). This ensures past values are preserved and only future values are resampled.
Precondition
Throws std::logic_error if any past disclosure has disclosureTime >= spawnTime. Throws std::logic_error if any pending disclosure has disclosureTime < spawnTime.
Parameters
originalThe scenario to be forked
spawnTimeFirst time point for resampling (systemState->getTime() + 1)
seedNew seed for resampling future values
