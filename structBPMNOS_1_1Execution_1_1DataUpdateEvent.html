BPMNOS::Execution::DataUpdateEvent Struct Reference

Represents the event of the environment of a run updating data or global attributes. More...

Detailed Description

The event names the data it changes by the scope declaring it and the identifier of the state machine holding it, which together name exactly one live state machine: the state machine of a process instance, of an instance of a multi-instance activity and of an instance of a non-interrupting event subprocess has an identifier of its own, and any other state machine shares the identifier of its parent, of which only one is alive at a time for a given scope. Global attributes are named without a scope. The event gives new values of scalar attributes, a value being undefined if it is not given, and new objects of object attributes.

Processing the event writes the values as an operator writes them, adds the changes of weighted attributes to the objective, and announces a DataUpdate naming the process instance, or the instance 0 for global attributes, so that restrictions, conditional events, deferrals and cached evaluations reading an attribute written are reconsidered as after any other change of data. The event takes effect at the time the run has reached; it changes neither the time, which only a ClockTickEvent changes, nor the timestamp of any token.
