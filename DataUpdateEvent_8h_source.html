19/**
20 * @brief Represents the event of the environment of a run updating data or global attributes.
21 *
22 * The event names the data it changes by the scope declaring it and the identifier of the state machine holding it,
23 * which together name exactly one live state machine: the state machine of a process instance, of an instance of a
24 * multi-instance activity and of an instance of a non-interrupting event subprocess has an identifier of its own,
25 * and any other state machine shares the identifier of its parent, of which only one is alive at a time for a given
26 * scope. Global attributes are named without a scope. The event gives new values of scalar attributes, a value
27 * being undefined if it is not given, and new objects of object attributes.
28 *
29 * Processing the event writes the values as an operator writes them, adds the changes of weighted attributes to the
30 * objective, and announces a @ref DataUpdate naming the process instance, or the instance 0 for global attributes,
31 * so that restrictions, conditional events, deferrals and cached evaluations reading an attribute written are
32 * reconsidered as after any other change of data. The event takes effect at the time the run has reached; it changes
33 * neither the time, which only a @ref ClockTickEvent changes, nor the timestamp of any token.
34 */
