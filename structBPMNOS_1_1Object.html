BPMNOS::Object Struct Reference

An object, i.e. an array or a structured value, stored flat. More...

Detailed Description

The values of an object are held in one vector, and its layout states where each of them is and, through its schema, what value type it has. An object is shared copy-on-write wherever it is held, as a std::shared_ptr<const Object>, so that copying a status or data copies no values.

BPMNOS::Object::Object ( const Schema & schema,
const nlohmann::json & json )

A JSON array is an array, whose elements have equal sizes at an open array and at most the declared size at a fixed one, a JSON object is an object, whose keys must be fields of the schema, and a number, truth value or text is a single value of the value type the schema states, null being undefined. A fixed array is padded with undefined values, an open array takes the size of the JSON array, and a field the JSON lacks is undefined.

◆ Object() [4/4]

BPMNOS::Object::Object ( const Schema & schema,
const Object & source )

At a value type, the source holds a single value of the same value type; arrays and objects are not cast. At an array type, the source is an array. A fixed array of size n has size n, a shorter source being padded with undefined elements and a longer source being cut off if every value beyond the n-th element is undefined and rejected otherwise; an open array has the size of the source. At an object type, the source is an object whose fields are fields of the target; a field the source lacks is undefined, every open array in it having size 0. Every part of the layout determined that equals the corresponding part of the layout of the source is that part, so that it is shared. A source that cannot be converted is rejected with an error.
